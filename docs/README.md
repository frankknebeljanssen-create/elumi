# Elumi — Dokumentation

Dauerhaft im Repo abgelegt, unabhängig von einzelnen Claude-Code-Sessions.

- **`dossier/index.html`** — interaktives Produkt- und Technik-Dossier (Didaktik,
  Architektur, technische Spezifikation, Arbeitsweise). Zielgruppe: Investoren,
  technische Kolleg:innen, potenzielle Arbeitgeber. Lokal öffnen mit
  `python3 -m http.server` im Ordner `docs/dossier/` und im Browser aufrufen,
  oder direkt als Datei öffnen (funktioniert offline, keine externen Abhängigkeiten).
- **`research/lernrhythmus-streak-briefing.html`** — Recherche-Grundlage für den
  Zielsystem-Umbau (August 2026): Streak-Mechanik, Tagesziel vs. Wochenziel,
  Spacing-Effekt, mit vollständigen Quellenangaben. Die Kernbefunde daraus sind
  im Dossier unter „Didaktik" zusammengefasst; hier steht die ausführliche Version.

Wird bei Bedarf um weitere Recherche-Dokumente ergänzt.
